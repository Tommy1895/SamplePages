# テトリス

ブラウザで遊べるシンプルなテトリスゲームです。

## 遊び方

1. `index.html`をブラウザで開きます。
2. キーボードの矢印キーを使ってブロック（テトリミノ）を操作します。

### 操作方法

- **矢印キー左 (←)**: ブロックを左に移動
- **矢印キー右 (→)**: ブロックを右に移動
- **矢印キー下 (↓)**: ブロックを早く落下させる
- **矢印キー上 (↑)**: ブロックを回転させる

## ルール

- 横一列がブロックで埋まると、その列が消えてスコアが加算されます。
- ブロックが画面の一番上まで積み上がるとゲームオーバーになり、盤面がリセットされます。
